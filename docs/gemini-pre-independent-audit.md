# 英単語2500マスター Pre編700問：Gemini独立監査指示書

対象リポジトリ：`keigohoriekameda/eigo-quiz`
対象ブランチ：`feature/vocab-2500-foundation`
対象ファイル：`data/pre-lv1-draft.json` ～ `data/pre-lv7-draft.json`（各100問）
目的：英語の正しい意味を知らなくても、品詞・カテゴリの違いだけで正答できてしまう四択問題を排除する。

## Geminiへの依頼文（そのまま貼り付け）

あなたは日本の小学生～中学生向け英単語教材の**独立した校閲者**です。添付した JSON ファイル（100問）を全問監査してください。作問者の判断を追認せず、問題点を厳しく指摘してください。

監査の優先順位：
1. **消去法の容易さ**：正解だけ動詞で誤答が名詞、正解だけ人名で誤答が物、国名だけに施設名が混じるなど、英単語を知らなくても解ける場合は NG。正答と誤答3個の品詞・意味カテゴリ・抽象度・形式を可能な限り合わせる。
2. **複数正解**：同義語、言い換え、日本語として実質的に同じ意味、語の複数義により誤答も正しくなる場合は最優先で NG。例：pretty / cute、ship / boat、sea / ocean、bike / bicycle、smart / clever。
3. **難易度**：同じ分野でもあまりに無関係な選択肢は改善。正答を覚えた子だけが安定して選べる、もっともらしい誤答にする。ただし不自然で難解な日本語は避ける。
4. **英語の正確性**：英単語の綴り、自然な例文、訳語、品詞、多義語、解説の適切さ。単語だけでは曖昧な場合は例文を添え、設問は「例文中の意味」を選ぶ形にする。
5. **学年との整合**：小学生Preとして不必要に難しい概念・語義や不自然な語句を指摘。

**重要**：
- `distractor_method` や `choice_group` が付いていても、質が保証されているわけではない。**必ず選択肢の中身で判断**する。
- `review_status` はすべて `draft`。あなた自身の監査だけで `approved` に書き換えない。
- 英単語は700学習項目の整合を維持する。削除する場合は代替語も提案する。ID、レベル、単元は維持する。
- 意味の近さだけを追うと複数正答になる。**「誤答として間違いであること」が必須条件**。
- 誤答を3つ必ず提案し、正答との重複・同義・表記ゆれを避ける。
- 前の会話や既存の「品質確認済み」という説明を信用せず、独立して判定する。

**出力形式**：
1. 集計：監査対象100問、重大NG・要改善・問題なし（暫定）の件数。
2. **重大NGと要改善の全件**について、表形式で `id / lemma / 問題点 / 修正版meaning_ja / 修正版distractors_ja（3個） / 修正版context_en / 修正版explanation_ja / 理由 / 優先度` を記載。
3. 改善後にも「複数正答がありうるもの」を再点検した一覧。
4. 判断できないものは「要人間確認」と明記し、推測で合格としない。

ファイルごとに100問を必ず確認し、**出力が長くなる場合は複数回に分割**してください。内容を省略せず、100問分のIDが監査対象に含まれたことを示してください。**直接GitHubやSupabase、本番アプリを書き換えないでください。** 変更案だけを返してください。

## 運用

- 7ファイルを一度に送らず、Lv.1～Lv.7を**1ファイルずつ**監査する。
- 最初に **Lv.1の100問**を送り、指摘が十分具体的か確認する。
- Geminiの提案をそのまま採用しない。ChatGPTで整合を再確認し、修正候補としてGitHubの開発ブランチに反映する。
- 修正後に `node scripts/audit-pre-quality.mjs` と `node scripts/audit-pre.mjs` を実行する。
- 重要な品質判定：誤答の不適切な品詞、意味領域の不一致、複数正答、文脈不明瞭、誤訳、実質的な消去法だけで解ける設問。
- 開発ブランチで検証し、本人の許可なく main マージ／デプロイ／ガチャ実付与を行わない。
