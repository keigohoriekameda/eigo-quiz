# 英単語2500マスター：実装仕様 v0.1

## ゴール
Pre 700語＋中学〜高校受験1,800語。神奈川県公立高校入試対策として、単語・熟語の意味だけでなく文脈理解・語形・用法を評価する。

## 区分（暫定配分、採録前に検証）
- PRE: 7ステージ×100項目 = 700
- MAIN: 10レベル×180項目 = 1,800
- MAINは中1・中2・中3・受験の4学年群にマッピングする。
- 同一見出し語がPRE/MAIN双方に現れる場合は、異なる意味や使い方を学ぶためであることを説明。見出し語数と重複を除いたユニーク語数は別々に表示する。
- 多義語や熟語の計上方式を問題データ上の unit_type で明示する。

## 問題品質ゲート
1. 四択の誤答は原則として品詞・意味領域・文脈が近いものを編集者が明示的に登録する（自動の完全ランダム抽出は使わない）。
2. 各問題に明示的な正答、3つ以上の一意な誤答、解説、出典・出題根拠、難易度を格納。
3. 選択肢は互いに重複せず、文脈で複数解となる問題を排除。複数解を許す場合は許容解を明示。
4. 綴り・訳語・英文自然性・学習指導要領との整合を校閲。
5. 過去問の全文転載を避け、過去問の傾向を参考にオリジナル問題を作る。
6. 未校閲問題は本番用の学習・ガチャ対象に入れない。

## 学習仕様
- ステージ内は20項目程度の小単元へ分割。各小単元合格基準は90%以上。
- 完了済み小単元は復習可能、報酬は二重付与しない。
- 合格前の誤答項目は復習キューへ登録。
- 20問で18問以上合格。未学習の問題だけでなく確認テストを設け、偶然の連続正解を減らす。
- ステージ・学年群の総合判定は全該当小単元合格で確定。学年区分マッピングは語彙監査後に確定。

## 報酬（生徒ID単位、サーバーで一意に付与）
- PRE_HALF_350: 350項目到達で通常ガチャ1回
- PRE_ALL_700: 700項目到達で通常ガチャ1回
- MAIN_G1_ALL / MAIN_G2_ALL / MAIN_G3_ALL / MAIN_EXAM_ALL: 各群完了で各1回
- ALL_2500_EXTRA: 全群完了時、Extraガチャ1回
- 最大通常6回＋Extra1回＝7回
- 同じユーザー・報酬キーの組をDB一意制約。クライアントからの成功申告だけで権利を付与しない。
- 既存のProject Skyline共通認証とガチャ付与APIを調査し、権限・署名・重複耐性を確認してから接続する。
- Discordは信頼できるサーバー側処理から送信。Webhook等の秘密情報を静的HTMLに置かない。
