# 英単語2500 問題データの管理

## 現在のデータ
- `pilot-reviewed.json`: 英単語20項目。四択の誤答候補を個別に設定した**機能検証用データ**。実際の入試頻度検証はまだ完了していない。
- 本番収録予定：Pre 700項目、Main 1,800項目。未収録分の空データやAIによるダミーを収録済みとして数えない。

## 編集手順
1. `docs/english-2500-spec.md` のスキーマに従ってJSONを作る。
2. 見出し語・訳語・英文・選択肢3件・解説の正しさを校閲する。
3. `node scripts/validate-vocabulary.mjs data/pilot-reviewed.json` で形式検査する（Node.jsが必要）。
4. 問題の内容・曖昧さは人間のチェックを行う。検査コードは語義の正しさを保証しない。
5. `vocab2500-preview.html` は `./data/pilot-reviewed.json` を読み込む。ローカルファイルの直接表示（file://）ではブラウザの制限で失敗することがあるため、HTTPサーバーから開く。

## 完成条件
- PreとMainの実データを検査し、700＋1,800項目を満たすこと
- 学年・単元ごとの90％合格と未学習・復習・誤答の区別が機能すること
- 生徒IDでのサーバー保存、ガチャ重複付与防止、Discord通知を認証済みAPIで検証すること
- 既存の公開版に変更を加える前にiPadなどで検証すること
